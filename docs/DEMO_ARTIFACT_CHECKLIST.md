# Demo Artifact Checklist

Use this checklist before sharing screenshots, decks, exports, screen recordings, or sample demo files with prospects. Demo artifacts must use synthetic/demo data only unless a customer has explicitly approved anonymized material for a controlled private pilot.

## Readiness Boundary

- [ ] Local demo is described as ready.
- [ ] Controlled private pilot is described as a conditional candidate.
- [ ] Public pilot is described as blocked.
- [ ] Public internet exposure is described as blocked.
- [ ] Production customer deployment is described as blocked.

## Data And Secret Hygiene

- [ ] No real customer data.
- [ ] No PII.
- [ ] No real customer names, client names, or campaign names.
- [ ] No API keys.
- [ ] No provider tokens.
- [ ] No OAuth credentials.
- [ ] No passwords.
- [ ] No graph credentials.
- [ ] No raw campaign briefs unless synthetic or explicitly approved and anonymized.
- [ ] No raw CRM records.
- [ ] No uploaded customer file contents.
- [ ] No generated report body from a real customer scenario.
- [ ] No internal logs, stack traces, tracebacks, request IDs, local file paths, or provider error dumps.
- [ ] No browser screenshots that expose auth headers, cookies, tokens, local storage, session storage, or settings secrets.

## Source And Provenance

- [ ] Demo Mode, Local Estimate, Live Backend, Backend Verified, or Unknown Source label is visible.
- [ ] Data basis is visible where the artifact includes export/deck metadata.
- [ ] Run ID or demo ID is visible only if safe and synthetic.
- [ ] Limitations slide or limitations section is included.
- [ ] Recommended validation step is included.
- [ ] Synthetic persona quotes are clearly understood as simulated output.

## Claim Safety

- [ ] No production-readiness claims.
- [ ] No public-pilot readiness claims.
- [ ] No public-internet readiness claims.
- [ ] No guaranteed prediction wording.
- [ ] No exact ROI/ROAS claims.
- [ ] No claims that 3C Simulator replaces market research.
- [ ] No claims that outputs are calibrated against real campaign outcomes unless that has been specifically validated.
- [ ] No claims that Demo Mode, Local Estimate, or synthetic fixtures are live backend evidence.

## Strategy Pack Export Checks

- [ ] Cover slide uses synthetic or approved placeholder context.
- [ ] Executive summary is framed as decision support.
- [ ] Decision Gate & KPI Summary avoids certainty language.
- [ ] Segment Reactions use synthetic/demo labels.
- [ ] Risk Drivers & Crisis Watchouts are included.
- [ ] Recommended Action Plan is included.
- [ ] Limitations & Recommended Validation slide is included.
- [ ] Every slide has a provenance footer.
- [ ] Footer includes source mode, data basis, safe run/demo ID if available, and "Decision-support estimate, not a guaranteed prediction".

## Final Share Decision

- [ ] Artifact is safe to share in a controlled sales conversation.
- [ ] Artifact owner has recorded which demo scenario was used.
- [ ] Artifact owner has recorded who reviewed the artifact.
- [ ] Artifact owner has recorded the date of review.
