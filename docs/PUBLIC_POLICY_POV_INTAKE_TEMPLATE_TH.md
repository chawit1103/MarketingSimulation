# Public Policy PoV Intake Template

ใช้ template นี้เพื่อเตรียมข้อมูลสำหรับ Strategic Command demo หรือ controlled private pilot discovery เท่านั้น ข้อมูลทุกช่องต้องได้รับอนุมัติจากทีมเจ้าของประเด็นก่อนนำเข้า demo

## Intake Fields

| Field | คำอธิบาย |
| --- | --- |
| ชื่อประเด็นหรือนโยบาย | ชื่อที่อนุมัติให้ใช้ใน demo หรือรหัส scenario แบบ anonymized |
| เป้าหมายของการสื่อสาร | ต้องการให้ผู้บริหารตัดสินใจอะไร เช่น launch, revise, hold, validate |
| กลุ่มประชาชนที่ได้รับผลกระทบ | ระบุเป็นกลุ่มกว้าง ไม่ใช้รายชื่อบุคคล |
| ความอ่อนไหวของประเด็น | ประเด็นเศรษฐกิจ สวัสดิการ สิทธิ ความปลอดภัย หรือความไว้วางใจ |
| ช่องทางสื่อสารหลัก | Facebook, TikTok, X, LINE, press briefing, town hall หรือ owned media |
| ข้อความแถลงเบื้องต้น | ข้อความที่ได้รับอนุมัติให้ใช้เป็น working draft |
| ความเสี่ยงที่กังวล | ความเข้าใจผิด ความไม่ไว้วางใจ การขยายความผิด หรือข้อกังวลเชิงวัฒนธรรม |
| คำถามที่ผู้บริหารต้องตัดสินใจ | ควรประกาศตอนนี้หรือไม่ ต้องปรับข้อความอะไร ต้องตรวจสอบอะไรเพิ่ม |
| กลุ่มที่อาจเข้าใจผิดหรือได้รับผลกระทบ | ระบุเป็น synthetic/public segment เท่านั้น |
| สิ่งที่ต้องการให้ระบบช่วยประเมิน | risk brief, crisis watchouts, message memo, response playbook หรือ strategy pack |

## Approval Checklist

- [ ] ประเด็นนี้ได้รับอนุมัติให้ใช้ใน demo หรือ workshop
- [ ] ข้อความแถลงเป็น draft ที่ผู้เกี่ยวข้องยอมรับให้ใช้เพื่อ simulation
- [ ] ไม่มีข้อมูลส่วนบุคคล
- [ ] ไม่มีรายชื่อประชาชน
- [ ] ไม่มี voter list
- [ ] ไม่มี raw CRM
- [ ] ไม่มี customer/contact records
- [ ] ไม่มี secrets, API keys, tokens, passwords หรือ auth headers
- [ ] ไม่มีข้อมูลดิบจากระบบภายในที่ยังไม่ได้รับอนุมัติ
- [ ] มีผู้รับผิดชอบ human review ก่อนนำผลลัพธ์ไปใช้

## Prohibited Inputs

- PII หรือข้อมูลระบุตัวบุคคล
- voter list หรือรายชื่อประชาชน
- raw CRM หรือ contact database
- ข้อมูลพฤติกรรมรายบุคคล
- ข้อมูลลับของหน่วยงานหรือพรรค
- credentials, tokens, passwords, provider keys
- ข้อความที่มีเจตนาปลุกปั่น สร้างข้อมูลบิดเบือน หรือทำร้ายฝ่ายตรงข้าม

## Use Boundary

Strategic Command ใช้เพื่อประเมินความเสี่ยงเชิงนโยบายและเตรียม executive decision support เท่านั้น ไม่ใช้เพื่อการแบ่งเป้ารายบุคคลทางการเมือง ไม่ใช้เพื่อการชักจูงรายบุคคล และไม่ใช้เพื่อสร้างหรือกระจายข้อมูลบิดเบือน

## Human Review Required

ก่อนสื่อสารสาธารณะจริง ต้องมีอย่างน้อย:

- policy owner review,
- legal/compliance review หากเกี่ยวข้อง,
- communications lead review,
- validation step ที่เหมาะกับประเด็น เช่น expert review, stakeholder review, survey หรือ field check.
