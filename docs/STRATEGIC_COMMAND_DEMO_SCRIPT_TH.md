# Strategic Command Demo Script

## Before The Demo

ถามผู้ชมก่อนเริ่ม:

- วันนี้อยากทดสอบประเด็นนโยบายหรือข้อความแถลงเรื่องใด
- ประเด็นนี้ได้รับอนุมัติให้ใช้ใน demo หรือไม่
- ผู้บริหารต้องตัดสินใจอะไรหลังดูผล
- กลุ่มประชาชนใดอาจได้รับผลกระทบหรือเข้าใจผิด
- ช่องทางสื่อสารหลักคือ Facebook, TikTok, X, LINE, press briefing หรือช่องทางอื่น
- มีข้อห้ามด้านข้อมูลหรือประเด็นอ่อนไหวอะไรบ้าง
- ใครเป็นผู้ทำ human review หลัง demo

ย้ำก่อนเปิดหน้าจอ:

- demo ใช้ข้อมูลที่ได้รับอนุมัติเท่านั้น
- ไม่ใช้ข้อมูลส่วนบุคคล รายชื่อประชาชน voter list หรือ raw CRM
- ผลลัพธ์เป็น decision-support estimate ไม่ใช่ผลจริง
- ต้องมี validation step ก่อนสื่อสารสาธารณะจริง

## 15-Minute Demo Script

| เวลา | สิ่งที่พูด | สิ่งที่แสดงบนหน้าจอ |
| --- | --- | --- |
| 0-2 นาที | แนะนำ Strategic Command ว่าเป็นห้องจำลองสถานการณ์สำหรับนโยบายและวิกฤตข่าวสาร | เปิด `/strategic-command` hero และ safety boundary |
| 2-4 นาที | เลือกประเด็นนโยบายหรือข้อความแถลง 1 เรื่อง | Policy / Public Issue Intake fields |
| 4-6 นาที | กำหนดกลุ่มประชาชนจำลองและช่องทางสื่อสาร | Intake field cards และ Four Pillars |
| 6-9 นาที | อธิบายการจำลองเสียงสะท้อนและความเสี่ยง | Crisis Intelligence และ Social Media Simulation |
| 9-11 นาที | เปิด crisis watchouts และจุดที่อาจถูกตีความผิด | Output Package cards |
| 11-13 นาที | ปรับ message / response playbook | Response Playbook blocks |
| 13-15 นาที | สรุปเป็น Executive Strategy Pack พร้อม validation step | Executive Strategy Pack preview และ CTA |

คำพูดปิด:

> สิ่งที่เราให้วันนี้ไม่ใช่การทำนายผลจริง แต่เป็น evidence สำหรับช่วยผู้บริหารเห็นความเสี่ยงก่อนตัดสินใจสื่อสาร

CTA:

> ทดลองกับประเด็นนโยบาย 1 เรื่องแบบ Controlled Private Pilot

## 30-Minute Workshop Script

| เวลา | กิจกรรม | เป้าหมาย |
| --- | --- | --- |
| 0-5 นาที | Confirm boundary | ยืนยัน no PII, no voter list, no raw CRM, approved data only |
| 5-10 นาที | Define issue | เลือกประเด็นและคำถามที่ผู้บริหารต้องตัดสินใจ |
| 10-15 นาที | Scenario framing | กำหนด synthetic personas, channels, sensitivity, risk concerns |
| 15-20 นาที | Simulation review | ดู public sentiment hypotheses และ crisis watchouts |
| 20-25 นาที | Message revision | ปรับ message, response playbook, validation step |
| 25-30 นาที | Executive close | สรุป Executive Strategy Pack และ next action |
