# PM2.5 Dust-Free Room Strategic Command Input

Source: Demo Mode | Basis: User-provided policy scenario | Run ID: demo-strategic-pm25-dust-free-room-001 | Decision-Support Estimate

เอกสารนี้เป็น demo input สำหรับ Strategic Command เท่านั้น รายละเอียดนโยบายทั้งหมดมาจาก user-provided scenario ไม่ใช่ข้อมูลลับ ไม่ใช่ข้อมูลประชาชนจริง และไม่ใช่หลักฐาน production

## Issue / Policy Name

**อววน. สู้ฝุ่น PM2.5: นำร่องนวัตกรรมห้องปลอดฝุ่นต้นทุนต่ำเพื่อสุขภาพประชาชน**

## Communication Goals

- สร้างการรับรู้ว่า อววน. สามารถนำงานวิจัยและนวัตกรรมมาใช้แก้ปัญหาในชีวิตประจำวันได้จริง
- สื่อสาร quick win ของกระทรวง อว. ต่อวิกฤต PM2.5
- ลดความเข้าใจผิดว่ารัฐมีแต่การสื่อสาร แต่ไม่มี action ที่จับต้องได้
- เตรียมรับมือคำถามเรื่อง scale, cost, proof, hidden costs, and long-term maintenance

## Affected Public Groups

- กลุ่มเปราะบาง เช่น เด็กเล็ก ผู้สูงอายุ ผู้ป่วยทางเดินหายใจ
- โรงเรียน ศูนย์เด็กเล็ก รพ.สต. และ อปท.
- ประชาชนในพื้นที่ภาคเหนือ
- ประชาชนทั่วไปที่ได้รับผลกระทบจาก PM2.5
- นักวิชาการ / เครือข่ายสิ่งแวดล้อม
- เกษตรกรหรือชุมชนที่อาจกังวลว่าถูกโยนความผิดเรื่องฝุ่น

## Issue Sensitivity

- สุขภาพประชาชนและความปลอดภัยของกลุ่มเปราะบาง
- ความเชื่อมั่นต่อความสามารถของรัฐในการแก้ปัญหาฝุ่น
- ความคุ้มค่าของงบประมาณและความโปร่งใสเรื่องต้นทุน
- ความเสี่ยงที่ถูกตีความว่าแก้ปลายเหตุแทนการจัดการต้นเหตุ
- ความเสี่ยงที่ชุมชนชนบทหรือเกษตรกรรู้สึกว่าถูกโยนความผิด

- TikTok: วิดีโอสั้นอธิบาย before/after, วิธีติดตั้ง, และเสียงจากพื้นที่

- Press briefing / executive memo: สรุปหลักฐาน ต้นทุน ข้อจำกัด และแผนขยายผล

## Initial Statement Message

> กระทรวง อว. เร่งนำงานวิจัยลงพื้นที่ช่วยเหลือประชาชน สู้ภัย PM2.5 นำร่องสร้างห้องปลอดฝุ่นต้นทุนต่ำเพียง 3,600 บาทต่อห้อง เสร็จแล้ว 83 แห่งใน 8 จังหวัดภาคเหนือ พิสูจน์แล้วว่านวัตกรรมไทยใช้งานได้จริง ปกป้องสุขภาพลูกหลานและผู้สูงอายุได้ทันที พร้อมเตรียมเปิดแบบแปลนให้ท้องถิ่นนำไปขยายผลต่อไป

Operator caution: ข้อความนี้เป็น initial statement to test เท่านั้น วลี “พิสูจน์แล้ว,” “ใช้งานได้จริง,” และ “ปกป้องสุขภาพ...ได้ทันที” ต้องถูกตรวจด้วย approved measurement evidence, installation evidence, และ human review ก่อนใช้เป็นข้อความสาธารณะ

## Anticipated Risks

| Risk | Why It Matters | Operator Note |
| --- | --- | --- |
| Performance skepticism | ห้อง 3,600 บาทกรองฝุ่นได้จริงหรือไม่ | ต้องเตรียมหลักฐานการวัดค่าฝุ่นและวิธีทดสอบ |
| Scale criticism | 83 ห้องน้อยเกินไปเมื่อเทียบกับพื้นที่ได้รับผลกระทบ | ควรสื่อสารว่าเป็น pilot model ไม่ใช่ผลสำเร็จสุดท้าย |
| Hidden costs | ค่าไฟ ค่าแผ่นกรอง ค่าบำรุงรักษา ใครรับผิดชอบ | ต้องมี cost breakdown และ ownership model |
| Root-cause criticism | แก้ปลายเหตุ ไม่แก้ต้นเหตุ | ต้องอธิบายว่าเป็นมาตรการลดผลกระทบระยะสั้นควบคู่กับงานต้นเหตุ |
| Political PR concern | ถูกมองว่าเป็นการประชาสัมพันธ์มากกว่านโยบายจริง | ควรให้ evidence, researcher voice, และ local implementer voice นำหน้า |

## Simulated Personas

### 1. Local Vulnerable Parent

พ่อแม่ที่มีลูกเล็กในจังหวัดภาคเหนือ กังวลเรื่องสุขภาพลูก ต้องการทางออกที่จับต้องได้ทันที

Likely reaction:

- สนใจเพราะต้นทุนต่ำและดูใกล้ตัว
- ต้องการรู้ว่าห้องอยู่ที่ไหน ใครเข้าใช้ได้ และวัดผลได้จริงหรือไม่
- อาจผิดหวังหากสื่อสารเหมือนช่วยได้ทั่วถึงทันที ทั้งที่ยังเป็นนำร่อง

### 2. Urban Skeptic

คนเมือง/ชาวเน็ตที่ติดตามข่าวการเมืองและงบประมาณรัฐ ตั้งคำถามเรื่องความคุ้มค่าและการแก้ปัญหาปลายเหตุ

Likely reaction:

- ถามว่าทำไมมีแค่ 83 ห้อง
- ต้องการเห็นตัวเลขทดสอบ ค่าใช้จ่ายจริง และผู้รับผิดชอบ maintenance
- อาจมองว่าเป็น PR ถ้าข้อความเน้นผลงานมากกว่าหลักฐาน

### 3. Local Implementer

ผู้นำชุมชน ผอ.โรงเรียน หรือ อปท. ที่สนใจนำไปใช้จริง แต่กังวลเรื่องงบซ่อมบำรุงและค่าใช้จ่ายระยะยาว

Likely reaction:

- สนใจแบบแปลนและ training
- ต้องการรู้ว่าใครซื้อ filter ใครดูแลระบบ และมีคู่มือหรือไม่
- ต้องการช่องทางติดต่อเพื่อขยายผล

### 4. Environmental Expert

นักวิชาการหรือเครือข่ายสิ่งแวดล้อมที่ต้องการ evidence, measurement, and root-cause policy alignment

Likely reaction:

- ต้องการเห็น methodology และ before/after measurement
- ต้องการให้สื่อสารว่ามาตรการนี้ไม่แทนการแก้ต้นเหตุ
- อาจช่วย validate หากได้รับข้อมูลที่โปร่งใส

### 5. Rural Community / Farmer

ชุมชนชนบทหรือเกษตรกรที่กังวลว่าจะถูกโยนความผิดเรื่องฝุ่นทั้งหมด

Likely reaction:

- ระวังข้อความที่เหมารวมว่าชุมชนเป็นต้นเหตุ
- ต้องการเห็นว่ามาตรการช่วยคนในพื้นที่ ไม่ใช่โยนภาระหรือกล่าวโทษ
- อาจตอบรับดีหากมีภาษาเคารพชุมชนและทางเลือกสนับสนุน

## Crisis Watchouts

- Influencer or journalist tests room with AQI meter and claims performance is weak
- Photos make the room look low-quality and become meme material
- Social backlash says government puts people in “boxes” instead of addressing root causes
- Criticism that 83 rooms are too few
- Questions about electricity/filter/maintenance costs

## Message Revision Recommendations

### Diagnosis

Original message is too achievement-led. It risks sounding like a finished solution before the public sees proof, scale plan, and maintenance details.

### Recommended Revision

> อว. ใช้งานวิจัยและนวัตกรรมเพื่อทดสอบโมเดลลดผลกระทบจาก PM2.5 ต่อสุขภาพประชาชน โดยเริ่มจากห้องปลอดฝุ่นต้นทุนต่ำ 3,600 บาทต่อห้อง นำร่อง 83 ห้องใน 8 จังหวัดภาคเหนือ เพื่อประเมินโมเดลที่ติดตั้งได้จริงในพื้นที่เสี่ยง พร้อมตรวจวัดผลและนำบทเรียนไปออกแบบการขยายผลร่วมกับพื้นที่และหน่วยงานที่เกี่ยวข้อง

### Why This Is Safer

- เปลี่ยนจาก “สำเร็จแล้ว” เป็น “นำร่องเพื่อพิสูจน์โมเดล”
- ลดความเสี่ยงถูกโจมตีเรื่อง scale
- เปิดพื้นที่ให้พูดเรื่อง evidence และ phase 2
- ยืนยันว่าการขยายผลต้องร่วมกับพื้นที่และหน่วยงานที่เกี่ยวข้อง

## Initial Response Playbook

### If attacked as “แก้ปลายเหตุ”

> อว. เข้าใจว่าการแก้ต้นเหตุเป็นเรื่องสำคัญและต้องทำควบคู่กัน แต่ในช่วงค่าฝุ่นสูง สุขภาพของเด็ก ผู้สูงอายุ และกลุ่มเปราะบางรอไม่ได้ ห้องปลอดฝุ่นเป็นมาตรการลดผลกระทบเร่งด่วนที่มีเป้าหมายเพื่อช่วยกลุ่มเปราะบางในพื้นที่เสี่ยง โดยควรสื่อสารควบคู่กับหลักฐานการติดตั้ง การตรวจวัด และผลการทดสอบที่ได้รับอนุมัติ

Operator note: ให้เชื่อมข้อความนี้กับนโยบายต้นเหตุหรือหน่วยงานที่รับผิดชอบต้นเหตุ โดยไม่กล่าวเกินข้อมูลที่ได้รับอนุมัติ และไม่สื่อสาร health-impact benefit แบบรับประกันผลหากยังไม่มี approved measurement evidence

### If attacked on “3,600 บาททำได้จริงหรือ”

> ควรสื่อสารพร้อมหลักฐานการทดสอบ มาตรฐานการติดตั้ง และตัวอย่างการวัดค่าฝุ่นก่อน-หลัง โดยให้ผู้เชี่ยวชาญหรือนักวิจัยอธิบาย

Operator note: ห้าม claim performance ถ้าไม่มี approved evidence ประกอบ

### If attacked on “83 ห้องน้อยเกินไป”

> 83 ห้องคือ sandbox / pilot model เพื่อพิสูจน์ความคุ้มค่าและวิธีติดตั้งจริง หากโมเดลผ่านการประเมิน จะใช้เป็นต้นแบบสำหรับการขยายผลร่วมกับท้องถิ่นและหน่วยงานที่เกี่ยวข้อง

Operator note: ต้องเตรียม phase 2 question, partner model, และ criteria สำหรับการขยายผล
