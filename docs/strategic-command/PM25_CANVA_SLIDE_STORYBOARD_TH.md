## Slide 4: Public Sentiment Risk Brief

### Slide Title

Public Sentiment Risk Brief

### Main Message

ความเสี่ยงหลักของ PM2.5 dust-free room demo ไม่ใช่แค่ “คนเห็นด้วยหรือไม่” แต่คือคำถามที่ต้องเตรียมหลักฐานและคำตอบก่อนสื่อสาร

### Suggested Visual

Five risk cards with icons or colored labels:

- Proof skepticism
- Scale criticism
- Hidden costs
- Root-cause criticism
- Political PR concern

### Thai Slide Copy

1. **Proof skepticism**: ห้อง 3,600 บาทกรองฝุ่นได้จริงหรือไม่  
2. **Scale criticism**: 83 ห้องน้อยเกินไปเมื่อเทียบกับพื้นที่ได้รับผลกระทบ  
3. **Hidden costs**: ค่าไฟ ค่าแผ่นกรอง ค่าบำรุงรักษา ใครรับผิดชอบ  
4. **Root-cause criticism**: แก้ปลายเหตุ ไม่แก้ต้นเหตุ  
5. **Political PR concern**: ถูกมองว่าเป็นการประชาสัมพันธ์มากกว่านโยบายจริง

### Speaker Notes

เป้าหมายของ brief นี้คือทำให้ทีมไม่โดนถามโดยไม่พร้อม โดยเฉพาะเรื่อง proof และ hidden costs ที่ควรมีข้อมูลอนุมัติก่อนใช้ public message

## Slide 5: Persona Reaction Map

### Slide Title

Stakeholder / Synthetic Persona Reaction Map

### Main Message

Synthetic Personas help the team see how different public groups may interpret the same policy message without using real personal data.

### Suggested Visual

Two-column map: persona name on the left, likely concern on the right.

### Thai Slide Copy

- **Local Vulnerable Parent**: ต้องการทางออกที่จับต้องได้ แต่ต้องเห็นหลักฐานว่าใช้ได้ในพื้นที่จริง
- **Urban Skeptic**: ถามเรื่องความคุ้มค่า scale และ proof
- **Local Implementer**: สนใจแบบแปลน แต่กังวล maintenance และงบระยะยาว

- **Rural Community / Farmer**: ระวังการสื่อสารที่ทำให้ชุมชนรู้สึกถูกโยนความผิดเรื่องฝุ่น

## Slide 6: Message Revision + Response Playbook

### Slide Title

ปรับข้อความจาก Achievement-Led เป็น Pilot Model for Scale

### Main Message

ข้อความเดิมเสี่ยงถูกมองว่า overclaim. ข้อความที่ปลอดภัยกว่าควรสื่อสารว่าเป็น pilot model, intended harm reduction, and evidence-led scaling.

### Suggested Visual

Before/After split:

- Left: Original message is achievement-led
- Right: Revised message frames it as pilot model for scale and harm reduction

Add three response chips:

- แก้ปลายเหตุ
- 3,600 บาททำได้จริงหรือ
- 83 ห้องน้อยเกินไป

### Thai Slide Copy

**Original message risk**  
ข้อความเดิมเน้น “สำเร็จแล้ว / ใช้งานได้จริง / ปกป้องสุขภาพได้ทันที” ซึ่งต้องมี approved evidence ก่อนสื่อสารสาธารณะ

**Recommended revision**  
อว. ใช้งานวิจัยและนวัตกรรมเพื่อทดสอบโมเดลลดผลกระทบจาก PM2.5 ต่อสุขภาพประชาชน โดยเริ่มจากห้องปลอดฝุ่นต้นทุนต่ำ 3,600 บาทต่อห้อง นำร่อง 83 ห้องใน 8 จังหวัดภาคเหนือ เพื่อประเมินโมเดลที่ติดตั้งได้จริงในพื้นที่เสี่ยง พร้อมตรวจวัดผลและนำบทเรียนไปออกแบบการขยายผลร่วมกับพื้นที่และหน่วยงานที่เกี่ยวข้อง

**Response Playbook**

- แก้ปลายเหตุ: เป็นมาตรการลดผลกระทบเร่งด่วนที่ต้องทำควบคู่กับการแก้ต้นเหตุ
- 3,600 บาททำได้จริงหรือ: สื่อสารพร้อมหลักฐานการติดตั้ง การตรวจวัด และผลทดสอบที่ได้รับอนุมัติ
- 83 ห้องน้อยเกินไป: สื่อสารว่าเป็น sandbox / pilot model เพื่อเรียนรู้ก่อนขยายผล

### Speaker Notes

จุดสำคัญคือเราไม่ได้ทำให้ข้อความดูสวยขึ้นเท่านั้น แต่ลด risk ของการสื่อสารเกินหลักฐาน โดยเฉพาะ health-impact claims ที่ต้องผูกกับ measurement evidence
