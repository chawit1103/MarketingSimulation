# PM2.5 Short Video Script

Purpose: 60-90 second Thai-first script for Canva video, Reels, LinkedIn, or Facebook. Tone should be executive, understandable, calm, and evidence-led.

Provenance: Demo Mode | Synthetic Scenario | Decision-Support Estimate

## Hook: 0-10s

**Visual:** PM2.5 headline card, navy background, simple dust-risk icon, no dramatic disaster footage.

**Voiceover / On-screen Text:**

PM2.5 ไม่ใช่แค่ปัญหาสิ่งแวดล้อม แต่เป็นโจทย์สุขภาพและความเชื่อมั่นของประชาชน

ก่อนสื่อสารนโยบาย เราควรรู้ก่อนว่าอะไรอาจถูกเข้าใจผิด

## Problem: 10-25s

**Visual:** Three-number tiles: 3,600 บาท / 83 ห้อง / 8 จังหวัดภาคเหนือ.

**Voiceover / On-screen Text:**

ใน demo นี้ เราใช้โจทย์ห้องปลอดฝุ่นต้นทุนต่ำ 3,600 บาท นำร่อง 83 ห้องใน 8 จังหวัดภาคเหนือ

โจทย์นี้มีทั้งโอกาสและความเสี่ยง: คนอาจถามว่ากรองฝุ่นได้จริงไหม 83 ห้องพอหรือไม่ ค่าไฟ ค่า filter และค่าบำรุงรักษาใครรับผิดชอบ

## System Explanation: 25-45s

**Visual:** Workflow: Policy Issue -> Synthetic Personas -> Crisis Watchouts -> Message Revision -> Response Playbook -> Executive Strategy Pack.

**Voiceover / On-screen Text:**

3C Simulator Strategic Command ช่วยจำลองความเสี่ยงการสื่อสารก่อนลงสนามจริง

ระบบใช้ Synthetic Personas เพื่อดูมุมมองที่อาจเกิดขึ้น เช่น ผู้ปกครองในพื้นที่เสี่ยง คนเมืองที่ตั้งคำถามเรื่องงบประมาณ ผู้ปฏิบัติงานท้องถิ่น และผู้เชี่ยวชาญสิ่งแวดล้อม

นี่คือ decision support สำหรับ public policy communication risk

## PM2.5 Demo Output: 45-70s

**Visual:** Output Package screenshot, risk cards, message revision card.

**Voiceover / On-screen Text:**

ผลลัพธ์คือ Public Sentiment Risk Brief, Crisis Watchout Brief, Message Revision Memo และ Response Playbook

ตัวอย่างเช่น ข้อความเดิมอาจดู achievement-led เกินไป เราจึงปรับให้เป็น pilot model for scale และ harm reduction ที่ต้องสื่อสารควบคู่กับหลักฐานการติดตั้งและการตรวจวัดที่ได้รับอนุมัติ

## CTA: 70-90s

**Visual:** CTA slide with safety footer.

**Voiceover / On-screen Text:**

Strategic Command ไม่ใช่การทำนายผลการเลือกตั้ง ไม่ใช่การประเมินผลต่อคะแนนเสียง และไม่ใช่การปั่นกระแสสังคม

นี่คือเครื่องมือสนับสนุนการตัดสินใจ เพื่อลดความเสี่ยงก่อนสื่อสารนโยบายสาธารณะ
