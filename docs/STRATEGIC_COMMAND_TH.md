# 3C Simulator Strategic Command

## Positioning

Strategic Command คือ vertical แยกสำหรับทีมสื่อสารภาครัฐ ทีมยุทธศาสตร์นโยบาย ทีมสื่อสารพรรคการเมือง และทีมที่ต้องประเมินความเสี่ยงของประเด็นสาธารณะก่อนสื่อสารจริง

หน้าที่ของ vertical นี้คือช่วยเตรียม decision-support evidence สำหรับ:

- policy communication risk review,
- public sentiment simulation แบบสมมุติ,
- crisis-information watchouts,
- message revision memo,
- executive decision support.

ผลลัพธ์ทั้งหมดต้องถูกมองเป็น **Local Estimate** หรือ **Demo Mode** จนกว่าจะมี backend/source label ที่เหมาะสม และต้องมี human review ก่อนนำไปใช้ในสถานการณ์จริง

## Why Separate From Marketing / Agency Proof-of-Value

`/proof-of-value` ถูกออกแบบสำหรับ brand, agency, PR, และ marketing operator ที่ต้องแปลง campaign brief เป็น output package ทางการตลาด

`/strategic-command` ถูกแยกออกมาเพื่อไม่ให้ผู้ชมภาครัฐหรือทีมยุทธศาสตร์ทางการเมืองเข้าใจว่า flow นี้เป็น campaign optimization หรือเครื่องมือซื้อสื่อ จุดเน้นคือ:

- risk before public communication,
- public issue framing,
- crisis readiness,
- culturally grounded synthetic personas,
- executive memo and response planning.

การแยก route, docs, และ demo script ทำให้ presenter อธิบายขอบเขตได้ชัดว่า vertical นี้ไม่ใช่เครื่องมือควบคุมความเห็นสาธารณะหรือระบบหาเสียงอัตโนมัติ

## Use Cases

- ทดสอบความเสี่ยงก่อนประกาศนโยบายหรือมาตรการใหม่
- ประเมินว่าข้อความแถลงอาจถูกตีความผิดตรงไหน
- จำลองเสียงสะท้อนเชิงสมมุติจากกลุ่มประชาชนที่ได้รับผลกระทบ
- เตรียม crisis watchouts สำหรับประเด็นอ่อนไหว
- สรุปทางเลือกและ next action ให้ผู้บริหาร
- วาง validation step ก่อนสื่อสารสาธารณะจริง

## Four Pillars

### 1. Crisis Intelligence

ทดสอบความเสี่ยงก่อนเป็นข่าวลบ วิเคราะห์ว่าประเด็นใดอาจถูกตีความผิด ขยายความผิด หรือกลายเป็นวิกฤตข่าวสาร

### 2. Social Media Simulation

จำลองกระแสบน Facebook, TikTok, X และ LINE ในฐานะ decision-support estimate เท่านั้น ไม่ใช่การฟัง social live และไม่ใช่การยืนยันผลลัพธ์จริง

### 3. Culturally Grounded Personas

ใช้ synthetic personas ที่มีบริบททางสังคมและวัฒนธรรมเพื่อฟังเสียงสะท้อนเชิงสมมุติ ไม่ใช้ข้อมูลประชาชนจริง รายชื่อประชาชน หรือ voter list

### 4. Executive-Ready Evidence

แปลงผลวิเคราะห์เป็น dashboard, memo, response playbook, และ Executive Strategy Pack เพื่อให้ผู้บริหารเห็นความเสี่ยง ทางเลือก และ next action อย่างรวดเร็ว

## Output Package

- Public Sentiment Risk Brief
- Crisis Watchout Brief
- Message Revision Memo
- Response Playbook
- Executive Strategy Pack
- Recommended Validation Step

## Safety Boundaries

- เป็นระบบสนับสนุนการตัดสินใจ ไม่ใช่คำทำนายผลลัพธ์จริง
- ไม่ใช้ข้อมูลส่วนบุคคล
- ไม่ใช้รายชื่อประชาชน
- ไม่ใช้ voter list
- ไม่ใช้ raw CRM
- ไม่ทำการแบ่งเป้ารายบุคคลทางการเมืองหรือ political microtargeting
- ไม่ใช่เครื่องมือปั่นกระแส
- ไม่ใช่เครื่องมือโจมตีฝ่ายตรงข้าม
- ไม่สร้างข่าวปลอมหรือข้อมูลบิดเบือน
- ไม่ทำนายผลการเลือกตั้ง
- ไม่ประเมินผลต่อคะแนนเสียง
- ต้องใช้ข้อมูลที่ได้รับอนุมัติเท่านั้น
- ต้องมี human review ก่อนสื่อสารสาธารณะจริง
